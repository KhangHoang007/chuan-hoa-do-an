Đồ án sai định dạng?
Chuẩn hóa lại trong 1 phút.

Tool tự sửa căn lề, font chữ, cỡ chữ, tiêu đề các cấp, mục lục tự động và số trang theo đúng quy định của trường — bạn chỉ cần chọn file và bấm một nút.

Học theo file mẫu của trường

Tải lên tối đa 4 file mẫu định dạng của trường/giảng viên — tool tự đọc quy tắc và áp đúng y hệt, không cần chỉnh tay từng thông số.

🎯

7 mẫu sẵn theo loại bài

Đồ án tốt nghiệp, khóa luận, tiểu luận môn học, báo cáo thực tập, nghiên cứu khoa học, thuyết minh khóa luận/đồ án...

🧹

Tự dọn lỗi bản thảo

Xóa in đậm/in nghiêng thừa ở thân văn, bỏ gạch đầu dòng dính vào đoạn văn, sửa mục lục gõ tay bị lệch, tiêu đề không còn đứng trơ ở cuối trang.

📑

Mục lục tự động + số trang

Tự chèn trang mục lục quét theo tiêu đề thật và đánh số trang — mở file trong Word, chuột phải → Update Field là hiện đủ.

🔒

Riêng tư của bạn

Bản web chỉ dùng file để xử lý rồi tự xoá ngay sau khi xong, không lưu lại. Ai kỹ tính có thể tải bản Windows chạy 100% offline trên máy mình.

⚡

Một phút là xong

Kéo thả file → chọn mẫu → bấm Chuẩn hóa → tải file kết quả. Việc trước đây ngồi sửa tay cả buổi tối.

Cách dùng — 3 bước

  1. Bấm nút "Dùng ngay trên web" ở trên (hoặc tải bản Windows rồi nhấp đúp để mở).
  2. Chọn file .docx cần chuẩn hóa, chọn mẫu định dạng (hoặc tải file mẫu của trường lên).
  3. Bấm "Chuẩn hóa ngay" và tải file kết quả về. Xong!

⚠️ Lần đầu mở, Windows có thể hiện cảnh báo xanh

Vì đây là phần mềm mới chưa có chữ ký số, Windows SmartScreen sẽ hỏi một lần. Cách mở:

  1. Bấm More info (Thông tin thêm).
  2. Bấm Run anyway (Vẫn chạy).

Các lần sau mở bình thường. Trong lúc dùng có một cửa sổ đen đi kèm — cứ để yên, đóng nó là tắt tool.

Câu hỏi thường gặp

Máy tôi không có Python / không rành máy tính, dùng được không?

Được. File .exe đã chứa mọi thứ bên trong — bạn chỉ cần Windows và biết nhấp đúp chuột.

File của tôi có bị gửi đi đâu không?

Không. Tool chạy hoàn toàn trên máy bạn, tắt mạng vẫn dùng bình thường.

Trường tôi có quy định riêng thì sao?

Chọn mục "Mẫu của trường / giảng viên" và tải file mẫu định dạng của trường lên (tối đa 4 file) — tool tự học và áp đúng bộ quy tắc đó.

Có dùng được cho Mac không?

Bản .exe dành cho Windows. Người dùng Mac vui lòng liên hệ để được hỗ trợ cách chạy thay thế.
