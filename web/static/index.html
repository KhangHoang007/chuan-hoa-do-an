Chuẩn Hóa Đồ Án

Định dạng lại file Word theo đúng quy định trình bày — khổ giấy, căn lề, font chữ, tiêu đề chương/mục, mục lục tự động, số trang. Chọn mẫu có sẵn hoặc tải file mẫu của trường/giảng viên để tool tự học đúng chuẩn đó.

1 · File cần chuẩn hóa
📄 Kéo thả file .docx vào đây, hoặc bấm để chọn
Tối đa 30 MB · File chỉ dùng để xử lý và tự xóa sau 1 giờ
2 · Chọn mẫu định dạng
📐 Thả file MẪU định dạng của trường/giảng viên vào đây
Tool sẽ đọc khổ giấy, căn lề, font, cỡ chữ, giãn dòng và kiểu tiêu đề từ file mẫu rồi áp đúng y hệt cho file của bạn. Chọn được tối đa 4 file mẫu — khi có nhiều file, tool gộp lại và lấy quy tắc phổ biến nhất.
3 · Tên file kết quả 4 · Tùy chọn thêm

✅ Chuẩn hóa xong!

⬇️ Tải file đã chuẩn hóa

Mẹo: mở file bằng Word — khi Word hỏi cập nhật trường dữ liệu (update fields) hãy chọn Yes để mục lục tự điền. Nếu chưa hiện: nhấp chuột phải vào mục lục → Update Field.

📐 Mẫu theo trường & giảng viênMỗi nơi một quy định riêng — tải file mẫu lên, tool tự trích xuất đúng bộ quy tắc đó thay vì bắt bạn chọn mò.
🗂️ Nhận diện tiêu đề thông minhChương, mục 1.1 / 1.1.1, chú thích Hình/Bảng được nhận diện kể cả khi gõ tay, thụt lề theo bậc thang từng cấp.
📑 Mục lục + số trang tự độngHai việc tốn thời gian nhất khi nộp bài được làm xong trong vài giây, kèm báo cáo từng hạng mục đã sửa.
Công cụ hỗ trợ định dạng — hãy đối chiếu lại với quy định chính thức của trường/khoa trước khi nộp bài.
